# Geordi Changelog

## 0.8.0

### Highlights

- Read what is new in each version of Geordi, with its highlights first, in Settings → Release notes and at geordi.run/releases. ([#446](https://github.com/chattocorp/geordi/pull/446))

### Features

- ⚠️ **BREAKING CHANGE:** You can no longer start new projects: the orchestrating workspaces outside any repository that you started with **New project** in the repository picker. Projects you already have keep working, and you can still archive and restore them; they will be removed entirely in a later version. To orchestrate work across repositories, ask the agent in any repository workspace: it can start agents in your other repositories. ([#376](https://github.com/chattocorp/geordi/pull/376))
- The model picker shows how much of each provider's usage is left, beside its models, so you can see where there is room before you switch. An idle workspace no longer replaces newer usage figures with older ones when the daemon reconnects, and a limit that has reset since its agent last spoke is no longer shown with its old figure. ([#443](https://github.com/chattocorp/geordi/pull/443))
- Clicking a workspace in the archive now offers to restore it, and takes you to it once restored. ([#393](https://github.com/chattocorp/geordi/pull/393))
- The sidebar now shows when an agent has left tasks running in the background, so you can see at a glance which workspaces are still busy after their turn ended. ([#395](https://github.com/chattocorp/geordi/pull/395))
- You can now see in the conversation where Claude or Codex compacted its context. ([#432](https://github.com/chattocorp/geordi/pull/432))
- Your repositories are now listed in the command palette: pick one to show only its workspaces in the sidebar. ([#431](https://github.com/chattocorp/geordi/pull/431))
- Your agent's context now shows as a signal-strength icon that weakens as the context fills up, and what is left of your usage limits for the model it uses as a battery. Both turn yellow as they run low and red when nearly out; hover either for the details, drawn the same way. ([#423](https://github.com/chattocorp/geordi/pull/423))
- An agent that started other agents is now told when one of them finishes a turn, with its reply. It no longer has to keep waiting for them, and cannot forget one that is done. ([#398](https://github.com/chattocorp/geordi/pull/398))
- Your archive groups workspaces by the day you archived them and shows the time beside each workspace. ([#389](https://github.com/chattocorp/geordi/pull/389))
- Sound files (WAV, MP3, Ogg, FLAC and M4A) now play right in Geordi: the file viewer opens them in a player, before and after a change, and when your agent puts one in a reply, you can play it there. ([#412](https://github.com/chattocorp/geordi/pull/412))
- Sound files now play in a player of Geordi's own, in the file viewer and in your agents' replies, with a waveform you can click to seek. A changed picture or sound shows its old and new versions together, the sounds drawn on one timescale, so you can compare them at a glance instead of switching between them. ([#416](https://github.com/chattocorp/geordi/pull/416))
- Double-click a workspace in the sidebar to open it with its conversation in front and the cursor in the reply box. ([#396](https://github.com/chattocorp/geordi/pull/396))
- A folder in your worktree that an agent names in its reply, as a path in code or a link, now opens in Finder when you click it. ([#411](https://github.com/chattocorp/geordi/pull/411))
- When one of your agents reads another workspace, it now gets one entry per turn: what the agent was told and its final answer, in pages small enough to fit in its context. So it sees much more of the conversation at once, without running out of room on long replies. ([#440](https://github.com/chattocorp/geordi/pull/440))
- Repository icons in the sidebar are raised like the cards around them, with a faint edge and a glassy sheen, so dark ones stand out in dark mode. A dark logo with no background of its own sits on a pale plate. ([#420](https://github.com/chattocorp/geordi/pull/420))
- Find anything by typing a few letters of it: press Cmd+Shift+P (Ctrl+Shift+P elsewhere) to go to any workspace, start a new one, add a repository, open the archive or a settings page, arrange the sidebar or change the appearance. In a workspace, Cmd+P (Ctrl+P) finds its conversations, terminals, tasks, windows, changed files and next steps. ([#399](https://github.com/chattocorp/geordi/pull/399))
- Checks still running now show a light going round their ring in the sidebar, like the one passing over the checks bar. ([#392](https://github.com/chattocorp/geordi/pull/392))
- While checks run on a pull request set to merge automatically, the checks ring in the sidebar now shows a green dot in its middle, so you can see at a glance that it will merge once they pass. ([#418](https://github.com/chattocorp/geordi/pull/418))
- In the sidebar's Today list, right-click a workspace and choose **Remove from Today** (or Shift-click it) to take it off the list. It comes back as soon as you send it a prompt. ([#417](https://github.com/chattocorp/geordi/pull/417))
- See what changed in each version of Geordi: in Settings → Release notes, and on the website at geordi.run/releases. ([#446](https://github.com/chattocorp/geordi/pull/446))
- Right-click a workspace in the sidebar and choose **Lock** to keep it from being archived, by you or by an agent, until you unlock it. ([#421](https://github.com/chattocorp/geordi/pull/421))
- You can now reorder the workspaces an agent started by dragging them among their siblings, at any depth. They keep their parent. ([#381](https://github.com/chattocorp/geordi/pull/381))
- In the desktop app, dropping a file that is not an image on the message box now types its full path into your message. ([#435](https://github.com/chattocorp/geordi/pull/435))

- Switch the sidebar between workspaces grouped by repository and one list, with each workspace marked by its repository’s icon. Press Cmd+Shift+G (Ctrl+Shift+G elsewhere) to switch. In one list, you can drag workspaces into any order. ([#380](https://github.com/chattocorp/geordi/pull/380))

New workspace is now above Archive and Settings at the bottom of the sidebar. ([#338](https://github.com/chattocorp/geordi/pull/338))
